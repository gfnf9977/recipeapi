
# 🍽️ Кулінарна CRM (Recipe Manager)

Легкий, швидкий та адаптивний веб-додаток для керування особистою колекцією рецептів. Проєкт дозволяє зручно структурувати інгредієнти, зберігати відеоінструкції (TikTok/YouTube), вести щоденник приготувань та залишати нотатки до конкретних варіацій страв.

🌍 **Live Demo:** [Подивитися проєкт в дії]([https://твій-посилання-на-render.onrender.com](https://recipeapi-hm5q.onrender.com/))

---

## ✨ Головні фічі

- **Миттєвий пошук:** Фільтрація рецептів за назвою або інгредієнтами в реальному часі на стороні клієнта.
- **Розумна інтеграція медіа:** Автоматичне отримання обкладинок з відео (TikTok/YouTube) через oEmbed API.
- **Трекінг приготувань:** Можливість відмічати приготовані страви, додавати власні фотозвіти та відкривати їх у повноекранному режимі (Lightbox).
- **Варіативність джерел:** Додавання нотаток до кожного окремого відео-джерела під одним рецептом (наприклад, *"тут автор використовує вершки замість молока"*).
- **Сортування інгредієнтів:** Динамічний поділ на обов'язкові компоненти та інгредієнти *"за смаком"*.

## 🛠 Технологічний стек

- **Backend:** C#, ASP.NET Core (Minimal APIs), Entity Framework Core
- **Frontend:** Vanilla JavaScript, HTML5, Tailwind CSS
- **База даних:** PostgreSQL (через [Neon.tech](https://neon.tech/))
- **Хмарне сховище:** [ImgBB API](https://api.imgbb.com/)

---

## 🏗 Архітектурні рішення

Для забезпечення швидкодії та надійності при розгортанні на безкоштовних хмарних серверах, у проєкті реалізовано два ключові рішення:

1. **Безсерверна база даних (Neon PostgreSQL)**
   Замість локальних чи тимчасових рішень, база даних винесена на хмарну платформу Neon. Це гарантує *"безсмертність"* даних, незалежність від перезапусків бекенд-сервера (наприклад, на Render) та забезпечує швидкий доступ завдяки сучасній архітектурі розділення обчислень і зберігання.

2. **Оптимізація зберігання медіафайлів (Zero-Footprint Storage)**
   Щоб не перевантажувати базу даних та не вичерпувати ліміти пам’яті важкими фотографіями користувачів, реалізовано механізм прямого завантаження:
   - Зображення відправляються на сервери **ImgBB** безпосередньо з клієнта.
   - У PostgreSQL зберігається лише легкий `URL-рядок` (менше 1 КБ).
   - Це дозволяє масштабувати проєкт до тисяч рецептів, зберігаючи базу даних максимально компактною та швидкою.

## 🚀 Встановлення та запуск (Локально)

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/твій-юзернейм/recipe-crm.git
   ```
2. Перейдіть у папку проєкту та налаштуйте рядок підключення до вашої бази PostgreSQL. Встановіть змінну середовища:
   ```bash
   set DB_CONNECTION_STRING=postgres://user:password@host:port/dbname
   ```
3. Запустіть проєкт (база даних та таблиці створяться автоматично завдяки `EnsureCreated`):
   ```bash
   dotnet run
   ```
